# Voyara

Location simulation for Android. Pick a point on the map and the device reports it
as the current fix, follow a route along real roads, or replay a GPX track.

- [Privacy policy](privacy.html)
- [Source on GitHub](https://github.com/broisnischal/voyara)

Voyara only supplies simulated locations after the device owner selects it under
*Developer options → Select mock location app*. Nothing is mocked until then.
